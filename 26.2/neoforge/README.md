# Useful Tools — NeoForge 26.2

This is the NeoForge 26.2 target for the unpublished Useful Tools `2.3.1`
matrix. It contains the full modern catalog, Spectral Infuser, Ghosts,
explosives, effects, and reinforced-gold world generation.

Minecraft 26.2, Java 25, and the exact NeoForge version in `gradle.properties`
are required. JEI and WTHIT are optional; JER remains disabled until a
compatible upstream release exists. The config screen is built from vanilla
Minecraft widgets and does not require Cloth Config.

Build from the repository root with:

```bash
scripts/build-matrix.sh 26.2-neoforge
```

See the root `README.md`, `COMPATIBILITY.md`, and `1.21.1/FUTURE_WORK.md` for
current status. `PORT_HANDOFF.md` and `CHANGELOG.md` are historical port records
and may describe superseded 2.2.x dependencies or validation.
