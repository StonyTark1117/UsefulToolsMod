# 2.3.0 runtime validation

This is live evidence for the unreleased 2.3.0 matrix. A Gradle build alone is
not recorded as runtime acceptance.

> Architectury note: references to the former 1.21.1 shared build and its
> transformer are preserved as historical evidence only. They were superseded
> by the loader-native Forge/Fabric/NeoForge migration; current acceptance must
> come from the independent targets and Architectury-free packaged artifacts.

## Final release-readiness result

PASS as of 2026-08-25. The dated sections below retain the failures and fixes
encountered while developing the gate; they are historical checkpoints and do
not override this final result.

- Clean strict build: all 16 binary and 16 source artifacts.
- Release audit: all 32 assembled files pass ZIP, metadata/version and packaged
  dependency-bound checks, Java class level, assets/data, exact
  682-recipe/848-advancement payload, source coverage, byte-size, and SHA-256
  checks. The 1.21.1 Forge binary now declares Forge and JavaFML `[52,)` rather
  than the template's ineffective `[0,)` floor.

  drift.

  game layer, free their listener, and leave no task-owned process.

  process.
- GameTests: 15/15 modern targets pass 96 required invocations. The 1.21.1
  loader trio also asserts representative tier durability, placed-worldgen
  registration, and infused-armor Ghost avoidance.
