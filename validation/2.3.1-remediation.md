# Useful Tools 2.3.1 remediation report

Date: 2026-08-26

Status: implementation and automated certification complete; maintainer visual
approval received through the explicit 2.3.1 publication request on 2026-08-27.

## Issue-by-issue remediation

### Ectoplasm Lantern

- Replaced the transparent full-cube placed model with bounded frame/cage
  geometry and a backed luminous core on all modern roots.
- Kept the canonical `ectoplasm_lantern` ID and deprecated `soul_lantern`
  compatibility alias, existing light/ward/redstone behavior, collision,
  recipes, drops, and saved data.
- Added distinct placed and inventory presentations, including equivalent
  Java 8 classic resources.
- Static resolver audit rejects item-model or item-texture references from the
  placed block and rejects missing backing geometry.
- Six directional client captures prove the model from all four sides, top,
  and bottom. Maintainer approval was received before publication.

### Mining Charge

- Replaced transparent `cube_all` presentation with solid-backed directional
  geometry.
- Added all six `FACING` variants and distinct unlit/lit models while retaining
  ownership, linking, remote detonation, ignition, and persistence behavior.
- Added a separate inventory representation and synchronized assets for all 16
  targets.
- Dedicated client captures show all six directions unlit and lit, plus two
  downward-facing states above glass with no exposed interior or floor-view
  alpha leak. Maintainer approval was received before publication.

### Wraith and WTHIT

- Added native Wraith WTHIT providers and descriptor registration everywhere
  WTHIT is supported.
- Tooltips expose hostile/ward-suppressed state, active Ectoplasm Lantern
  response, and ordinary-versus-infused weapon effectiveness without copying
  Ghost biology.
- Four live Wraith captures cover hunting/warded and ordinary/infused state
  combinations; a Ghost capture verifies the existing provider remains intact.
- The 42-profile integration matrix proves all optional integrations absent-safe
  and supported present profiles load-safe. A separate WTHIT-absent client run
  reached a world and exited cleanly.

### Wraith and block behavior contracts

- Loader-native GameTests now cover lantern light, ward, redstone, collision,
  and persistence; charge direction, lit state, ownership/linking, ignition,
  remote detonation, and persistence; and Wraith config, ward, flight/lunge,
  fire, damage, loot, and advancement behavior.
- Event-driven advancement awards use the advancement's declared remaining
  criteria instead of assuming a hard-coded `trigger` criterion.
- Wraith lunge production logic exposes a testable activation method while the
  normal tick path delegates to the same behavior.
- All 15 modern targets pass 111 required GameTest invocations. The 1.21.1
  Forge GameTest server reports all seven required tests passed but its Gradle
  launcher does not self-terminate; the harness terminates that owned launcher
  after a ten-second grace period and verifies that no owned PID remains.

### Advertised catalog and compatibility

- Canonical catalog, registration/config tables, recipes, loot, advancements,
  language, renderers, block entities, and optional-integration declarations
  were audited across all targets.
- The exact 26.2 Fabric startup message now reports Minecraft 26.2 rather than
  the inherited 26.1.2 port label.
- Forge 1.7.10 remains included and passes Java 8 build, server, client, asset,
  and release-content gates.
- Fabric binaries pass unchanged on Quilt Loader 0.30.0 for all five supported
  Minecraft versions.
